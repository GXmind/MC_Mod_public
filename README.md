# 墨韵 InkBrush

Minecraft Java Edition 毛笔武器模组公开发布仓库。本仓库只提供编译完成的模组文件，不公开源代码。

## 下载

| Minecraft 版本 | 加载器 | 模组文件 |
| --- | --- | --- |
| 1.20.1 | Fabric | `inkbrush-1.0.0+mc1.20.1.jar` |
| 1.21.11 | Forge 61.2.1 | `inkbrush-1.0.0+mc1.21.11-forge.jar` |

## 安装

1. 安装与游戏版本对应的 Fabric 或 Forge 加载器。
2. 下载上表对应的 JAR 文件。
3. 将 JAR 放入该游戏实例的 `mods` 文件夹。
4. 启动游戏。

Fabric 1.20.1 版本还需要安装对应版本的 Fabric API。

## 主要内容

- 新武器：毛笔，基础最终攻击伤害 10，攻速中等。
- 墨量上限 400；短按右键消耗墨水甩出墨水攻击。
- 新物品：墨水瓶，可按毛笔实际缺失量补充墨水。
- 墨水标记可施加黑暗、清除生物锁定并造成易伤。
- 附魔“一点笔墨浸染，晕开阴阳”提供水墨太极阵与乾坤移位传送能力。
