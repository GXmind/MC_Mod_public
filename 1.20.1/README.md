# 墨韵 InkBrush — Minecraft 1.20.1

## 版本信息

| 项目 | 内容 |
| --- | --- |
| Minecraft | 1.20.1 |
| 加载器 | Fabric |
| 模组版本 | 1.0.0 |
| Java | Java 17 |
| 额外依赖 | 与 Minecraft 1.20.1 对应的 Fabric API |

## 下载

[下载 `inkbrush-1.0.0+mc1.20.1.jar`](./inkbrush-1.0.0+mc1.20.1.jar)

## 安装

1. 创建或选择 Minecraft 1.20.1 Fabric 实例。
2. 安装与该实例匹配的 Fabric API。
3. 将本目录中的 JAR 放入实例的 `mods` 文件夹。
4. 确保 `mods` 中没有其他 Minecraft 版本的 InkBrush JAR，然后启动游戏。

## 主要内容

- 毛笔：基础最终攻击伤害 10，攻速中等，墨量上限 400。
- 墨水瓶：总补充量 1600，可根据毛笔实际缺失墨量进行补充。
- 短按右键：消耗 10 点墨水发动墨水攻击，使目标获得黑暗与易伤标记。
- 被标记目标失去锁定；玩家使用毛笔攻击该目标时造成 165% 伤害。
- 附魔“一点笔墨浸染，晕开阴阳”：提供水墨太极阵与乾坤移位传送能力。
