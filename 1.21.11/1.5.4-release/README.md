| 项目 | 内容 |
| --- | --- |
| Minecraft | 1.21.11 |
| 加载器 | Forge 61.2.1 |
| 模组版本 | 1.5.4-release |
| Java | Java 21 或更高版本的兼容运行时 |
| 视觉实现 | VFS 关闭；使用稳定版非 VFS 表现 |

## 下载

[下载 `inkbrush-1.5.4-release+mc1.21.11-forge.jar`](./inkbrush-1.5.4-release+mc1.21.11-forge.jar)

## 安装

1. 创建或选择 Minecraft 1.21.11 / Forge 61.2.1 实例。
2. 删除 `mods` 文件夹内旧版 InkBrush JAR，避免重复加载或网络协议冲突。
3. 将本目录中的 JAR 放入实例的 `mods` 文件夹。
4. 启动游戏并在 Forge 模组列表中确认版本为 `1.5.4-release`。

## 1.5.4-release 更新内容

- 重新设计画布编辑界面，采用紧凑布局并根据当前GUI尺寸自动缩放。
- 保留256×256画布数据精度，同时缩小屏幕占用面积。
- 修复右键擦除操作不能立即显示、保存后才消失的问题。
- 修复连续绘制与擦除操作的客户端预览确认顺序。
- 修复长时间绘制后关闭画布导致自定义网络包解码失败并断开连接的问题。
- 将笔画坐标改为8KB以内的位图编码，完整画布笔画仍只结算一次墨水、染料与耐久。
- 画布网络协议升级至版本2；客户端与服务器必须安装同一版本JAR。
