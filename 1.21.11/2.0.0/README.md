## 版本信息

| 项目 | 内容 |
| --- | --- |
| Minecraft | 1.21.11 |
| 加载器 | Forge 61.2.1 |

| Java | Java 21 或更高版本的兼容运行时 |

## 版本定位

这是 InkBrush 第二代架构的第一个正式公开版本。新架构从 `2.0.0` 开始，后续所有新架构迭代统一使用 `2.x` 版本号；`1.x` 已冻结，`1.6.0-vfs-release` 是旧架构最后一版。

## 下载

[下载 `inkbrush-2.0.0+mc1.21.11-forge.jar`](./inkbrush-2.0.0+mc1.21.11-forge.jar)

## 2.0.0 主要内容

- 物品、技能、数值和视觉意图提取到加载器无关的公共组件。
- 1.21.11 使用独立项目组合根、强覆盖和 Forge API 适配器。
- 太极阵、传送阵、墨锁囚灵、封魔绘图与水墨弹统一通过独立 VFX 接口组织。
- 特效同步实体、客户端 Mesh/BER 渲染和图片资源分目录维护。
- 保留 1.6.0 的完整玩法与重构后的水墨视觉表现。
- 构建版本由单一配置生成，JAR 文件名与 Forge 模组列表中的版本保持一致。

## 安装或升级

1. 使用 Minecraft 1.21.11 / Forge 61.2.1 实例。
2. 从实例 `mods` 文件夹删除所有旧版 InkBrush JAR，不能与 1.x 同时安装。
3. 将本目录中的 2.0.0 JAR 放入 `mods` 文件夹。
4. 启动游戏并在 Forge 模组列表确认版本为 `2.0.0+mc1.21.11-forge`。

建议升级前备份世界存档。不要把本 JAR 用于 Fabric、Minecraft 1.20.1 或其他游戏版本。
