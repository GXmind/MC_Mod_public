# 墨韵 InkBrush — 1.4.0

## 版本信息

| 项目 | 内容 |
| --- | --- |
| Minecraft | 1.21.11 |
| 加载器 | Forge 61.2.1 |
| 模组版本 | 1.4.0 |
| Java | Java 21 或更高版本的兼容运行时 |

## 下载

[下载 `inkbrush-1.4.0+mc1.21.11-forge.jar`](./inkbrush-1.4.0+mc1.21.11-forge.jar)

## 安装

1. 创建或选择 Minecraft 1.21.11 / Forge 61.2.1 实例。
2. 删除 `mods` 文件夹内旧版 InkBrush JAR，避免重复加载。
3. 将本目录中的 1.4.0 JAR 放入实例的 `mods` 文件夹。
4. 启动游戏并在 Forge 模组列表中确认“墨韵 InkBrush 1.4.0”已加载。

## 1.4.0 更新内容

- 新增木、铜、铁、金、下界合金五种毛笔，耐久分别为 1000、1500、2000、2500、5000。
- 每次战斗使用消耗 10 点耐久，毛笔支持锋利、亡灵杀手、经验修补等原版附魔。
- 新增毛笔战斗升级系统：击杀生物获得经验，墨量上限从 400 逐步提升，最高 1500。
- 新增附魔“数缕玄毫倾泻，断分死生”。
- 右键蓄力释放“墨锁囚灵”：消耗 120 墨，在 22 格内生成 8×8 墨狱，禁锢并施加易伤与凋零；已被普通墨水标记的目标会延长禁锢并受到更强凋零。
- 左键蓄力释放“死生判笔”：消耗 180 墨，高生命目标受到无视部分护甲的穿刺伤害，低生命目标受到巨额斩杀伤害；蓄力期间受击会无消耗打断。
- 同一毛笔同时拥有两本战斗附魔时，右下角显示两套独立技能组，可用 `Ctrl+,` 切换。
- 新增墨雾囚笼、浓墨束、暗红缠笔光与墨色斩击视觉效果。
- 包含 1.3.0 的笔筒、笔架交互以及“封魔绘图”生物标记、动画封印、释放和召回功能。
