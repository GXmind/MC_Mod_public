# 墨韵 InkBrush — 1.4.1

## 版本信息

| 项目 | 内容 |
| --- | --- |
| Minecraft | 1.21.11 |
| 加载器 | Forge 61.2.1 |
| 模组版本 | 1.4.1 |
| Java | Java 21 或更高版本的兼容运行时 |

## 下载

[下载 `inkbrush-1.4.1+mc1.21.11-forge.jar`](./inkbrush-1.4.1+mc1.21.11-forge.jar)

## 安装

1. 创建或选择 Minecraft 1.21.11 / Forge 61.2.1 实例。
2. 删除 `mods` 文件夹内旧版 InkBrush JAR，避免重复加载。
3. 将本目录中的 1.4.1 JAR 放入实例的 `mods` 文件夹。
4. 启动游戏并在 Forge 模组列表中确认“墨韵 InkBrush 1.4.1”已加载。

## 1.4.1 更新内容

- 封魔绘图释放的生物会永久记录主人，不会仇视或伤害任何玩家；主人攻击非玩家生物后，释放生物会主动协助追击和攻击。
- 右下角技能组界面精简为四枚 16×16 技能图标，不再显示技能名称、按键、墨量、等级和耐久文本。
- “墨锁囚灵”会持续显示凋零状态，并每秒扣除目标最大生命值的 10%；目标已有普通墨水标记时，延续强化规则并提升为 20%。
- 移除遮挡视野的“死生判笔”蓄力环绕与命中斩击粒子，保留技能伤害、声音和墨狱结界提示。
- 修复高等级毛笔写入墨量时仍被错误限制为 400 的问题，升级后的墨量上限可正确生效。
- 包含 1.4.0 的多材质毛笔、耐久、战斗升级及“数缕玄毫倾泻，断分死生”技能组。
