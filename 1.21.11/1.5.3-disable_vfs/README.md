# 墨韵 InkBrush — 1.5.3-disable_vfs

## 版本信息

| 项目 | 内容 |
| --- | --- |
| Minecraft | 1.21.11 |
| 加载器 | Forge 61.2.1 |
| 模组版本 | 1.5.3-disable_vfs |
| Java | Java 21 或更高版本的兼容运行时 |
| 视觉实现 | VFS 关闭；使用稳定版非 VFS 表现 |

## 下载

[下载 `inkbrush-1.5.3-disable_vfs+mc1.21.11-forge.jar`](./inkbrush-1.5.3-disable_vfs+mc1.21.11-forge.jar)

## 安装

1. 创建或选择 Minecraft 1.21.11 / Forge 61.2.1 实例。
2. 删除 `mods` 文件夹内旧版 InkBrush JAR，避免重复加载。
3. 将本目录中的 JAR 放入实例的 `mods` 文件夹。
4. 启动游戏并在 Forge 模组列表中确认版本为 `1.5.3-disable_vfs`。

## 1.5.3-disable_vfs 更新内容

- 保存后的画幅仍可再次打开并多次编辑；对空气右键或潜行右键进入编辑，对墙右键正常放置。
- 右键字帖会自动寻找背包内第一张可编辑画布或画幅，应用模板后直接打开临摹界面。
- 画布新增 16 色笔触选择与 4 档笔触粗细。
- 1.21.11 画布升级为 256×256 细像素表面，连续拖动会生成连贯笔迹。
- 字帖使用抗锯齿连续笔画骨架，不再直接显示为放大的方形像素块。
- 画布客户端入口和网络通道与战斗、传送等全局机制隔离。
- 旧版 64×64 画布数据会在 1.21.11 中自动迁移为高分辨率画布。
- 本版本明确关闭实验性 VFS 特效实现，便于稳定验证书画机制。
