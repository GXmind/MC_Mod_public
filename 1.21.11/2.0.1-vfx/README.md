## 版本定位

`2.0.1-vfx` 是第二代架构的首个水墨特效增强测试版本，基于 `2.0.0` 的完整玩法实现，重点重构 Forge 1.21.11 客户端渲染管线。



## 下载

[下载 `inkbrush-2.0.1-vfx+mc1.21.11-forge.jar`](./inkbrush-2.0.1-vfx+mc1.21.11-forge.jar)

## 本版主要内容

- 新增 Forge 原生 `RenderPipeline` 与 GLSL 330 水墨渲染体系。
- 太极阵使用单层程序化圆形 Mesh，具备完整阴阳构图、噪声晕染、鱼眼脉动和缓慢流转。
- 太极结界改为黑白交替、反向流动的破碎水墨气带。
- 普通泼墨攻击改为相机朝向的连续 Ribbon Mesh 笔触，不再以粒子流或墨囊作为主体。
- 墨锁囚灵使用动态水墨网格牢笼，并保持玩家无碰撞通行。
- 水池渐黑使用连续浓度着色与动态噪声流动。
- 封魔绘图动画中的墨线接入新版笔触渲染。
- 新增 `AUTO`、`ENHANCED`、`COMPATIBLE` 三档客户端特效模式。
- 增加远距离 Mesh 精度降级和透明渲染排序优化。

## 安装或升级

1. 使用 Minecraft 1.21.11 / Forge 61.2.1 实例。
2. 从实例 `mods` 文件夹删除所有旧版 InkBrush JAR。
3. 将本目录中的 JAR 放入 `mods` 文件夹。
4. 启动游戏并在 Forge 模组列表确认版本为 `2.0.1-vfx+mc1.21.11-forge`。

建议升级前备份世界存档。不要把本 JAR 用于 Fabric、Minecraft 1.20.1 或其他游戏版本。
