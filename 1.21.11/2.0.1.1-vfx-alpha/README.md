# InkBrush 2.0.1.1-vfx-alpha

这是 Minecraft 1.21.11 Forge 版水墨毛笔模组的 VFX Alpha 测试构建。

## 运行环境

- Minecraft：1.21.11
- Forge：61.2.1
- Java：21 或更高版本
- 模组文件：`inkbrush-2.0.1.1-vfx-alpha+mc1.21.11-forge.jar`

## 本次视觉调整

- 加深太极阵、墨锁囚灵和泼墨弹道的冷黑墨色，提高透明度与视觉冲击力。
- 增强太极阵边缘结界、墨锁环带以及弹道笔锋的可读性。
- 特效实体最大可见距离提高至约 320 格；实际显示仍受客户端视距、实体距离和区块加载状态限制。
- 服务端实体追踪范围提高至 24 个区块。
- 太极阵远距 LOD 使用 40 / 32 / 24 段渐进降级，兼顾远距离轮廓与性能。
- 保留正常光照响应，没有使用全亮渲染。

## 安装

1. 关闭游戏。
2. 删除 `mods` 目录内旧版 InkBrush JAR，避免同时加载多个版本。
3. 将本目录中的 JAR 放入 Minecraft 1.21.11 Forge 61.2.1 实例的 `mods` 目录。
4. 使用 Java 21 启动游戏。
