# 墨韵 InkBrush — 1.5.0

## 版本信息

| 项目 | 内容 |
| --- | --- |
| Minecraft | 1.21.11 |
| 加载器 | Forge 61.2.1 |
| 模组版本 | 1.5.0 |
| Java | Java 21 或更高版本的兼容运行时 |

## 下载

[下载 `inkbrush-1.5.0+mc1.21.11-forge.jar`](./inkbrush-1.5.0+mc1.21.11-forge.jar)

## 安装

1. 创建或选择 Minecraft 1.21.11 / Forge 61.2.1 实例。
2. 删除 `mods` 文件夹内旧版 InkBrush JAR，避免重复加载。
3. 将本目录中的 1.5.0 JAR 放入实例的 `mods` 文件夹。
4. 启动游戏并在 Forge 模组列表中确认“墨韵 InkBrush 1.5.0”已加载。

## 1.5.0 更新内容

- 太极阵与传送阵改用完整水墨 Mesh：多层透明面片、旋转、UV 滚动和柔化墨边；传送阵不再生成边缘结界。
- 普通墨水弹改为自定义投射物渲染，不再显示墨囊或持续生成飞行粒子，并增加带状水墨拖尾和命中泼墨效果。
- “墨锁囚灵”改为固定数量的旋转 Display 水墨面片组成牢笼，结界视觉与玩法判定分离。
- 封魔绘图封印动画改为多组 Display 时序动画，表现画卷飞出、展开、环绕、绘符和返回。
- 封闭小水池的渐黑水面新增方块实体渲染，使用滚动噪声水墨层表现污染程度。
- 毛笔新增第一人称动态握笔、挥笔和蓄力姿态，浸水与浸墨状态继续自动切换材质。
- 临时视觉实体均不写入世界存档，结束或取消时会自动清理。
