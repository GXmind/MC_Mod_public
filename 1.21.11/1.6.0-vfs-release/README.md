## 重要声明

**这是 InkBrush 旧版代码架构的最后一个正式发行版。**

本版本保留为稳定运行、兼容测试和必要回退使用。后续功能开发与多版本适配将转入新的公共组件/项目适配层架构，旧版架构不再继续叠加新功能。

## 下载

[下载 `inkbrush-1.6.0+mc1.21.11-forge.jar`](./inkbrush-1.6.0+mc1.21.11-forge.jar)

## 主要更新

- 重构水墨太极阵、传送阵、墨锁囚灵、封魔绘图等视觉表现。
- 普通泼墨改用连续笔触弹道与带状拖尾，不再使用墨囊模型作为视觉主体。
- 水池渐黑改为浓度驱动的动态水面渲染。
- 增加毛笔手持、蓄力和攻击动作表现。
- 视觉资源与服务器时间同步，保持多人环境中的动画进度一致。

## 安装

1. 创建或选择 Minecraft 1.21.11 / Forge 61.2.1 实例。
2. 从实例的 `mods` 文件夹中移除其他 InkBrush JAR，避免重复加载。
3. 将本目录中的 JAR 放入该实例的 `mods` 文件夹。
4. 启动游戏并在 Forge 模组列表中确认 InkBrush 已加载。
