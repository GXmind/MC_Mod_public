## 本版主要内容

- 包含 2.0.1-vfx 的 Forge 原生水墨 Mesh、Ribbon、着色器与分级兼容渲染。
- 新增技能驱动的地图环境联动：泼墨显路、墨锁搭桥、太极阵眼、洗笔灵池、驱散墨雾和震山落石。
- 地形交互由服务端真实技能事件触发，并使用地图 Marker 锚点限制作用位置与范围。
- 临时地形变化写入持久恢复事务；不会覆盖玩家后续修改，也不会接管容器等方块实体。
- 太极阵眼可临时激活地图墨石并强化对应阵法；永久地形变化仅允许修改地图专用封印块。
- 环境实现已通过 Forge 无头 GameTest，独立环境数据包也通过真实服务器加载解析。

## 安装

1. 使用 Minecraft 1.21.11 / Forge 61.2.1 实例。
2. 删除实例 `mods` 文件夹内其他 InkBrush JAR，避免重复加载和网络协议冲突。
3. 将本目录中的 `1.21.11_vfx_env_2.0.1.0.jar` 放入 `mods` 文件夹。
4. 启动游戏，在 Forge 模组列表中确认 InkBrush 已加载。

环境交互需要安装配套作者地图及锚点；在普通随机世界中不会自动替换原版世界生成器或破坏原版地形。建议测试前备份存档。
