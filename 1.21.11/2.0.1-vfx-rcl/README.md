# 墨韵 InkBrush 2.0.1-vfx-rcl

这是 Minecraft 1.21.11 / Forge 61.2.1 的新版水墨特效候选版本。`rcl` 表示本构建仍处于 VFX 验收阶段，请与旧版本分开保存。

## 运行环境

- Minecraft：1.21.11
- Forge：61.2.1
- Java：21 或更高版本
- 模组文件：`inkbrush-2.0.1-vfx-rcl+mc1.21.11-forge.jar`

## 本版重点

- 重构 VFX 基础层、调用层、效果层、Mesh 数学层和 Forge 渲染管线。
- 太极阵使用完整阴阳鱼单层圆面，并加入落笔、墨染扩散、非机械缓慢流转和断续阴阳气脉。
- 传送阵沿用单层太极表现，但不会生成边缘结界。
- 普通右键泼墨改为连续 Catmull-Rom Ribbon 笔触，不显示墨囊，也不以持续粒子流作为主体。
- 墨锁囚灵改为稀疏螺旋墨筋与断环，玩家可自由穿过，禁锢仍由服务器逻辑处理。
- 封魔绘图使用服务器时间戳驱动的分阶段动画。
- 洗笔染池采用邻格浓度插值和动态水墨噪声。
- 全套颜色调整为冷灰中性，移除旧版偏黄宣纸色和全亮贴片感。

## 安装

1. 安装 Minecraft 1.21.11 与 Forge 61.2.1。
2. 删除 `mods` 文件夹内其他版本的 InkBrush JAR，避免重复加载。
3. 将本目录中的 JAR 放入该游戏版本的 `mods` 文件夹。
4. 启动游戏后先在单人世界验证太极阵、泼墨、墨狱、封印和染池表现。
