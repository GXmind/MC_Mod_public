# 墨韵 InkAura 3.3.0

适用环境：Minecraft Java Edition `1.21.1`、NeoForge `21.1.250`、Java 21。

模组文件：`inkaura-3.3.0+mc1.21.1-neoforge.jar`

## 本次更新

- 为太极扇加入「一扇清风留影，回身已斩浮生」与「半卷阴阳晦朔，一扇浮生明灭」两套战技：飞扇旋切、瞬移斩击，以及阴阳切换、浮影、斩影与三影终结。
- 加入炼丹炉、丹药、鉴定笺、丹典等基础炼丹玩法；丹药结果由材料属性、配比、炉级与随机扰动共同决定。
- 增加炼丹界面、配方及中英文说明；炼丹系统的规则与算法说明保存在私有开发仓库，公开仓库不包含源代码。

内部模组 ID 和资源命名空间仍为 `inkbrush`，用于兼容旧世界与资源，不影响 InkAura 品牌名称。

## 安装

将本目录中的 JAR 放入对应实例的 `mods` 文件夹，并先移除或禁用旧版 InkBrush/InkAura JAR。不要同时加载两个版本。

Photon 2、LDLib2 与 KilaGraph 为可选特效编辑环境，不是基础玩法的强制依赖。
