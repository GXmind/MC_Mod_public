# 墨韵 InkAura 3.3.6-alchemy-refine

适用：Minecraft **1.21.1** · **NeoForge 21.1.250** · Java **21**。

[下载模组 JAR](./inkaura-3.3.6-alchemy-refine+mc1.21.1-neoforge.jar) · [返回版本列表](../README.md)

## 本次更新

- 修复开扇时扇面缺失；阴扇采用暗色、阳扇采用亮色的独立模型，并同步开合过渡外观。
- 优化飞扇技能：沿水平方向飞出，模型以水平姿态旋转。
- 重构炼丹炉和丹道界面：柔和宣纸/玉灰配色、圆角面板，按炉品质、丹药属性和火候区分颜色；统一槽位布局，增加不能开炉原因、燃料和收丹提示。
- 调整材料价值、属性组合、冲突、失败率与品质随机分布；昂贵材料与普通材料有更清晰的差异，但不保证每炉高品质。品质与稀有异变分别判定。
- 炼丹读取材料携带的原版药水效果及附魔信息；优化药效组合与特殊词条，降低重复药效和不合理随机叠加。
- 修复燃料数值同步、收丹权限及炼制中材料显示与自动化取物的隔离问题。
- 保留旧版在炼批次的算法兼容；已有丹药不重新随机生成。

## 基本玩法

使用炼丹炉配置主药、辅药、药引和燃料，选择火候后开炉，观察进度与收丹提示。材料、炉品质、炼丹技艺、火候及收丹时机共同影响结果。丹药可带品质、属性、药效、丹毒及特殊词条；请先查看物品提示和丹道界面再服用。

太极扇保留双附魔玩法：飞扇悬停后可瞬移斩击；阴扇普通攻击留下浮影，切换阳扇可斩影并触发连招。此次重点修复外观和飞行姿态。

第四阶段的炼丹师 NPC、交易、任务、Boss 材料及大型天地异象暂缓，不属于本版已完成内容。

## 安装与升级

1. 关闭游戏，备份世界存档。
2. 确认实例为 Minecraft 1.21.1 / NeoForge 21.1.250，并使用 Java 21。
3. 将本目录 JAR 放入实例的 `mods` 文件夹，禁用旧 InkAura/InkBrush JAR，避免重复加载。
4. 重启游戏。内部模组 ID 仍为 `inkbrush`，用于旧世界兼容，不是未更名。

Photon 2、LDLib2、KilaGraph 不是本版强制依赖；本目录不分发第三方模组。本包不能用于 Forge 1.21.11 或 Fabric 1.20.1。
