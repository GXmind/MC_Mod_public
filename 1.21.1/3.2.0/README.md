# 墨韵 InkAura 3.2.0

适用环境：Minecraft Java Edition `1.21.1`、NeoForge `21.1.250`、Java 21。

模组文件：`inkaura-3.2.0+mc1.21.1-neoforge.jar`

## 本次更新

- 毛笔笔头改用真实曲面网格与独立笔毫纹理，增大笔头并呈现毛束纹路；木、铜、铁、金、下界合金毛笔共用几何，保留干燥、浸墨、浸水状态。
- 太极扇扇面扩大并重映射为闭合扇形，外缘贴合扇骨与两侧护骨，不再出现扇骨远超扇面的比例问题。
- 保留 3.1.0 的开扇、合扇和 10 秒无动作自动合扇机制；扇子战斗技能仍待后续版本加入。

内部模组 ID 和资源命名空间仍为 `inkbrush`，用于兼容旧世界与资源，不影响 InkAura 品牌名称。

## 安装

将本目录中的 JAR 放入对应实例的 `mods` 文件夹。请先移除或禁用旧版 InkBrush/InkAura JAR，不要同时加载两个版本。

Photon 2、LDLib2 与 KilaGraph 为可选特效编辑环境，不是基础玩法的强制依赖。
