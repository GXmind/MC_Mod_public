# 墨韵 InkAura 3.1.0

适用环境：

- Minecraft Java Edition `1.21.1`
- NeoForge `21.1.250`
- Java 21

模组文件：`inkaura-3.1.0+mc1.21.1-neoforge.jar`

## 品牌更名

从本版本起，“墨韵 InkBrush”正式更名为“墨韵 InkAura”。为避免既有世界中的物品、方块、附魔和玩家数据失效，内部模组 ID 与资源命名空间继续使用 `inkbrush`。因此日志、资源包或高级指令中出现 `inkbrush:*` 属于兼容设计。

## 3.1.0 更新内容

- 新增太极水墨扇武器外观，正面构图包含完整阴阳图、水墨山河、九根扇骨、双侧护骨、玉珠与黑白流苏。
- 新增独立折扇模型；收拢状态仍能辨认九根叠合扇骨，不再表现为单根长方体。
- 右键可主动开扇或合扇；开扇后 10 秒无动作会自动收扇。
- 开合过程加入四个真实几何过渡帧，并同步第一人称手腕动作。
- 开扇采用“压腕蓄力—爆发甩开—末端回弹”，合扇采用“反扣—聚拢—制动回弹”，强化重量与发力感。
- 扇面样式依据正面参考图制作，并修复 Blockbench 外部纹理缺失导致的绿色方块问题。
- 延续 3.0.0 的五种毛笔、墨量成长、双技能组、封魔绘图、画布字帖、笔筒笔架和洗笔染池功能。

当前版本先提供扇子模型、状态和动画，扇子专属战斗技能将在后续版本开发。

## 安装方法

1. 安装 Minecraft 1.21.1、NeoForge 21.1.250 与 Java 21。
2. 将本目录中的 `inkaura-3.1.0+mc1.21.1-neoforge.jar` 放入实例的 `mods` 文件夹。
3. 删除或将旧版 InkBrush/InkAura JAR 改为 `.disable`，不可同时加载多个版本。
4. 启动游戏，在模组列表中确认“墨韵 InkAura 3.1.0”已经加载。

Photon 2、LDLib2 与 KilaGraph 仅用于可选特效编辑和测试，不包含在 InkAura JAR 内，也不是基础玩法的强制依赖。
