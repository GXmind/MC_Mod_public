# 墨韵 InkBrush — Minecraft 1.21.1

本目录收录 Minecraft 1.21.1 / NeoForge 21.1.250 的公开发行包。不同模组版本使用独立目录，目录中仅包含对应 JAR 和说明文档。

## 可用版本

| 模组版本 | 状态 | 下载与说明 |
| --- | --- | --- |
| 3.0.0 | 当前版本；1.21.1 NeoForge 移植与 Photon 2 测试基础 | [进入 3.0.0](./3.0.0/) |

请勿同时安装多个 InkBrush JAR。升级前先从实例的 `mods` 目录移除旧版本。

Photon 2 与 LDLib2 是可选的客户端特效编辑环境，不是运行 InkBrush 3.0.0 的强制依赖。
