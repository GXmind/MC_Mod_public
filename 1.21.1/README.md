# 墨韵 InkAura — Minecraft 1.21.1

本目录收录 Minecraft 1.21.1 / NeoForge 21.1.250 的公开发行包。项目从 `3.1.0` 起正式更名为 InkAura；`3.0.0` 保留历史名称 InkBrush。不同模组版本使用独立目录，目录中仅包含对应 JAR 和说明文档。

## 可用版本

| 模组版本 | 状态 | 下载与说明 |
| --- | --- | --- |
| **3.3.0** | **当前版本**；太极扇双附魔战技与炼丹玩法 | [进入 3.3.0](./3.3.0/) |
| 3.2.0 | 历史版本；真实曲面毛笔笔头、扇面与扇骨比例修正 | [进入 3.2.0](./3.2.0/) |
| 3.1.0 | 历史版本；InkAura 品牌启用、太极水墨扇模型与开合动画 | [进入 3.1.0](./3.1.0/) |
| 3.0.0 | 历史版本；1.21.1 NeoForge 移植、三维文房美术资源更新与 Photon 2 测试基础 | [进入 3.0.0](./3.0.0/) |

请勿同时安装多个 InkAura/InkBrush JAR。升级前先从实例的 `mods` 目录移除或禁用旧版本。

Photon 2、LDLib2 与 KilaGraph 是可选的客户端特效编辑环境，不是运行 InkAura 3.3.0 的强制依赖。
